# Contributing

Found a directory we missed, or one that died? PRs welcome.

## What belongs on this list

- ✅ A real, active directory that accepts third-party submissions
- ✅ Has a clear submission URL or path
- ✅ Is reasonably well-known, or has DR / traffic worth noting
- ❌ Personal blogs or single-product sites
- ❌ Dead, redirected, or domain-parked sites
- ❌ Paid-only listings disguised as free directories

## How to suggest a directory

Open a PR that adds an entry in the right section, following this format:

```md
- **[Directory Name](https://example.com)** _(DR 42, 50K traffic)_ — One-sentence description, under 140 chars.
```

The stats tag is optional — leave it off if you don't have the numbers.

## How to report a dead directory

Open an issue with the directory name and any details (redirected, returns 404, paid-only now, etc).
